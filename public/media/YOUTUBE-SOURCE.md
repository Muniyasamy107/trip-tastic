## Brightness is not resolution

The publisher advertises this film as 4K. An 8K stream has NOT been verified.
There is no claimed upscaling, fabricated 8K label, deprecated setPlaybackQuality
call or ineffective vq parameter. YouTube chooses adaptive playback quality from
available streams based on the browser, device, network and provider policy.
The enlarged, unfiltered player exposes native quality controls. It cannot offer
an 8K stream if the uploader/provider does not supply one.

The header uses a lighter emerald overlay and a modest CSS brightness(1.16),
saturate(1.08), contrast(1.02) lift on the background iframe. This brightens the
rendered picture, not its pixel resolution. The enlarged player is not filtered.
The background uses 4% cover overscan; the native modal shows the full player.

No video binary was downloaded, extracted, re-hosted or committed. The official
thumbnail is requested by the browser from i.ytimg.com, including reduced-motion
and completed-tab views. A static cover crop removes its baked-in thumbnail bars;
it is never presented as a moving video or an 8K still. The old New Zealand
screenshot is no longer deployed as the hero poster.

The official IFrame API controls one privacy-enhanced youtube-nocookie.com embed.
Muted autoplay is best-effort. It stays in the same DOM host for background and
enlarged views, pauses offscreen/when motion is disabled, and is removed after
completion. Session completion prevents another API/embed load in the completed
tab when storage is available. YouTube frame capture is unavailable, so the
thumbnail is restored, not a fabricated final frame. A new selection/revision
plays once independently of completion records for the previous film.

YouTube controls branding, ads, available quality, regions and embedding
permissions. Privacy-enhanced mode is not a promise of no tracking or storage.
An oEmbed response is metadata, not a marketing reuse licence or a guarantee of
streaming on every deployment. Confirm promotional embedding rights before launch.
A shared link is not permission to download or redistribute the film.

The restricted coding environment cannot independently stream the live film.
